# Quote wallpapers

Four selected preview concepts, generated with the built-in image_gen tool, normalized to exactly **1200 × 660 px** with aspect-preserving resampling and centered cropping. Original generated files were preserved. The bot selects a saved wallpaper locally on each new quote; it does not call image generation at runtime.

## Generation prompts

Each asset used the following common prompt plus its corresponding palette paragraph.

Use case: stylized-concept. Asset type: preview-only background concept for a Telegram bot quote card, landscape about 20:11 aspect ratio. Create a finished full-bleed flat 2D chat wallpaper inspired by Telegram's recognizable playful doodle wallpapers. A smooth soft gradient overlaid with thin hand-drawn outline doodles: tiny paper airplanes, speech bubbles, smiling cats, coffee cups, stars, moons, little clouds, hearts, game controllers and small abstract squiggles. Consistent restrained fine line weight, spacious interlocking pattern, tasteful low contrast. The doodles must remain visible but quiet, about 7 percent contrast; reduce pattern density slightly in the middle-left where a large quotation will later be overlaid. Crisp clean modern digital wallpaper, no texture noise, no 3D, no shadows, no perspective. Background only: absolutely NO text, labels, numbers, logos, avatars, quote lettering, chat bubbles containing text, borders, UI, or mockup frames. Fill the entire image to every edge.

1. **light.png:** Palette: classic pale pistachio, light sky blue and warm ivory, a subtle airy gradient. Doodles muted sage green/blue, suitable for dark navy quote text. Cheerful classic Telegram chat wallpaper atmosphere.
2. **night.png:** Palette: rich midnight navy, desaturated deep teal and a soft subdued blue glow at the upper right. Doodles in low-contrast slate blue. Dark elegant Telegram night theme, designed for white quote text, keep the background genuinely dark.
3. **lilac.png:** Palette: a soft lavender, cool periwinkle and a delicate blush pink gradient. Doodles low-contrast dusty violet. Light sophisticated Telegram-inspired wallpaper, suitable for dark plum quote text. Avoid saturated neon.
4. **mint.png:** Palette: soft mint, pale turquoise and a gentle warm lemon glow in one corner. Doodles low-contrast muted teal. Fresh light Telegram-inspired wallpaper, suitable for deep teal quote text. Quiet airy premium design.
